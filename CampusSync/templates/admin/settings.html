Email / SMS Integration

Email, SMS and push delivery are intentionally not implemented. No SMTP or SMS provider credentials are available in this environment, so rather than faking a delivery, notifications are delivered in-app through the notification centre. This is the clean integration boundary: adding a real provider later means writing a dispatcher in security.notify() and leaving the rest untouched.

External Systems (SIS / SSO)

Student information system and single sign-on are also not connected. User accounts are managed locally by the administrator. The users table is the single source of student identity, so an SIS import would only need to populate that table.
